## 2. 斐波那契数列测试用例

### 2.1 测试目标
实现斐波那契数列计算：Fib(n)，验证流水线CPU的功能正确性。

### 2.2 算法描述

```
计算斐波那契数列第n项
输入: n (存储在$1中)
输出: Fib(n) (存储在$2中)

算法:
if (n <= 1) return n;
else return Fib(n-1) + Fib(n-2);

实现方式：迭代法
$1 = n
$2 = 0 (Fib(0))
$3 = 1 (Fib(1))
for i = 2 to n:
    $4 = $2 + $3  (新的Fib)
    $2 = $3       (更新前一项)
    $3 = $4       (更新当前项)
```

### 2.3 MIPS汇编程序

```assembly
# 初始化
addi $1, $0, 11        # n = 11 (因为循环条件i<n,要计算Fib(10)需要设n=11)
addi $2, $0, 0         # Fib(0) = 0
addi $3, $0, 1         # Fib(1) = 1
addi $4, $0, 2         # i = 2 (循环计数器)

# 主循环
loop:
    slt  $5, $4, $1    # $5 = (i < n) ? 1 : 0
    beq  $5, $0, end   # if (i >= n) goto end
    add  $6, $2, $3    # $6 = Fib(i-2) + Fib(i-1)
    add  $2, $3, $0    # $2 = $3 (移动前一项)
    add  $3, $6, $0    # $3 = $6 (保存当前项)
    addi $4, $4, 1     # i++
    slt  $5, $4, $1    # $5 = (i < n) ? 1 : 0
    bne  $5, $0, loop  # if (i < n) goto loop

end:
    sw   $3, 0($0)     # 保存结果到内存MEM[0]
    lw   $7, 0($0)     # 读取结果验证
    halt               # 停机
```

### 2.4 机器码(十六进制)

**MIPS.txt内容:**
```
08 01 00 0B    # addi $1, $0, 11      (PC=0x00)
08 02 00 00    # addi $2, $0, 0       (PC=0x04)
08 03 00 01    # addi $3, $0, 1       (PC=0x08)
08 04 00 02    # addi $4, $0, 2       (PC=0x0C)
98 81 28 00    # slt  $5, $4, $1      (PC=0x10) loop开始
D0 A0 00 06    # beq  $5, $0, end     (PC=0x14, offset=6, 目标0x30)
00 43 30 00    # add  $6, $2, $3      (PC=0x18)
00 60 10 00    # add  $2, $3, $0      (PC=0x1C)
00 C0 18 00    # add  $3, $6, $0      (PC=0x20)
08 84 00 01    # addi $4, $4, 1       (PC=0x24)
98 81 28 00    # slt  $5, $4, $1      (PC=0x28)
D4 A0 FF FA    # bne  $5, $0, loop    (PC=0x2C, offset=-6, 目标0x10)
C0 03 00 00    # sw   $3, 0($0)       (PC=0x30) end标签
C4 07 00 00    # lw   $7, 0($0)       (PC=0x34)
FC 00 00 00    # halt                 (PC=0x38)
```

**关键修正点**:
1. `n = 11` (0x0B) - 使循环执行到i=10
2. `beq offset = 6` (0x06) - 从0x14跳转到0x30 = (0x30-0x14-4)/4 = 6
3. `bne offset = -6` (0xFFFA) - 从0x2C跳转到0x10 = (0x10-0x2C-4)/4 = -6
4. `slt` 指令编码 - 98 81 28 00 (正确的rs/rt顺序)

## 3. 测试用例设计

### 3.1 基础指令测试

#### Test 1: 算术运算
```assembly
addi $1, $0, 10       # $1 = 10
addi $2, $0, 20       # $2 = 20
add  $3, $1, $2       # $3 = 30
sub  $4, $2, $1       # $4 = 10
```

**预期结果**: $3=30, $4=10

#### Test 2: 逻辑运算
```assembly
ori  $1, $0, 0xFF     # $1 = 0xFF
ori  $2, $0, 0xF0     # $2 = 0xF0
and  $3, $1, $2       # $3 = 0xF0
or   $4, $1, $2       # $4 = 0xFF
```

**预期结果**: $3=0xF0, $4=0xFF

#### Test 3: 访存操作
```assembly
addi $1, $0, 100      # $1 = 100
sw   $1, 0($0)        # MEM[0] = 100
lw   $2, 0($0)        # $2 = MEM[0] = 100
```

**预期结果**: $2=100, MEM[0]=100

---

### 3.2 数据冒险测试

#### Test 4: RAW冒险（可前推）
```assembly
add  $1, $2, $3       # $1 = $2 + $3
add  $4, $1, $5       # $4 = $1 + $5 (需要前推$1)
```

**观察点**:
- ForwardA应该被设置为10（从EX/MEM前推）
- 无需暂停流水线

#### Test 5: Load-Use冒险（需暂停）
```assembly
lw   $1, 0($0)        # $1 = MEM[0]
add  $2, $1, $3       # $2 = $1 + $3 (需要暂停1周期)
```

**观察点**:
- PC_Write = 0（暂停1周期）
- IF_ID_Write = 0
- ID_EX_Flush = 1（插入气泡）

---

### 3.3 控制冒险测试

#### Test 6: 分支指令
```assembly
addi $1, $0, 10
addi $2, $0, 10
beq  $1, $2, target   # 相等，跳转
addi $3, $0, 1        # 不应执行
target:
addi $4, $0, 2        # 应该执行
```

**观察点**:
- IF_Flush = 1（清空addi $3指令）
- 最终$3=0, $4=2

**BNE指令测试**:
```assembly
addi $1, $0, 10
addi $2, $0, 20
bne  $1, $2, target   # 不相等，跳转
addi $3, $0, 1        # 不应执行
target:
addi $4, $0, 2        # 应该执行
```

**观察点**:
- IF_Flush = 1（清空addi $3指令）
- 最终$3=0, $4=2

#### Test 7: 跳转指令
```assembly
j    target
addi $1, $0, 1        # 不应执行
target:
addi $2, $0, 2        # 应该执行
```

**观察点**:
- IF_Flush = 1
- 最终$1=0, $2=2

## 6. 性能评估指标

### 6.1 基本指标

```
CPI (Cycles Per Instruction) = 总周期数 / 总指令数

IPC (Instructions Per Cycle) = 1 / CPI

流水线效率 = 实际IPC / 理想IPC × 100%

加速比 = 多周期CPU时间 / 流水线CPU时间
```

### 6.2 冒险统计

```
Load-Use冒险率 = Load-Use冒险次数 / 总指令数 × 100%

数据前推率 = 前推次数 / 总指令数 × 100%

控制冒险率 = 分支/跳转次数 / 总指令数 × 100%
```

## 7. 常见问题排查

### 7.1 指令执行错误

**现象**: 计算结果不正确

**排查步骤**:
1. 检查ALU运算逻辑
2. 验证控制信号是否正确
3. 检查寄存器读写是否正常
4. 查看前推逻辑是否工作

### 7.2 流水线暂停异常

**现象**: 流水线一直暂停

**排查步骤**:
1. 检查PC_Write信号
2. 验证冲突检测逻辑
3. 查看Load-Use检测条件

### 7.3 数据冒险未处理

**现象**: 数据前推不工作

**排查步骤**:
1. 检查ForwardingUnit逻辑
2. 验证寄存器地址比较
3. 查看前推MUX选择信号
