# 顶层设计

## 1. 系统架构概览

### 1.1 五级流水线CPU整体结构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         PipelineCPU 顶层模块                             │
│                                                                          │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐  ┌────────────┐       │
│  │  IF Stage  │─→│  ID Stage  │─→│  EX Stage  │─→│ MEM Stage  │─→ ... │
│  │   取指阶段  │  │  译码阶段   │  │  执行阶段   │  │  访存阶段   │       │
│  └────────────┘  └────────────┘  └────────────┘  └────────────┘       │
│         │              │              │              │                  │
│         ↓              ↓              ↓              ↓                  │
│    ┌────────┐    ┌────────┐    ┌────────┐    ┌────────┐               │
│    │ IF/ID  │    │ ID/EX  │    │EX/MEM  │    │MEM/WB  │               │
│    │流水线   │    │流水线   │    │流水线   │    │流水线   │               │
│    │寄存器   │    │寄存器   │    │寄存器   │    │寄存器   │               │
│    └────────┘    └────────┘    └────────┘    └────────┘               │
│                                                                          │
│  ┌─────────────────────┐         ┌─────────────────────┐               │
│  │  HazardDetection    │         │  ForwardingUnit     │               │
│  │  冲突检测单元        │         │  前推单元            │               │
│  │  - Load-Use检测     │         │  - EX冒险检测        │               │
│  │  - 控制冒险检测      │         │  - MEM冒险检测       │               │
│  └─────────────────────┘         └─────────────────────┘               │
│           │                                    │                        │
│           ↓ (暂停/清空信号)                     ↓ (前推控制)             │
│       各流水线阶段                            ALU                        │

```

## 2. 顶层模块接口

### 2.1 端口定义

```verilog
module PipelineCPU(
    // ===== 基本控制信号 =====
    input CLK,                      // 系统时钟
    input RST,                      // 异步复位（低电平有效）
    
    // ===== 调试观察接口 =====
    // PC相关
    output [31:0] curPC,            // 当前程序计数器值
    
    // IF阶段
    output [31:0] IF_PC,            // IF阶段的PC
    output [31:0] IF_instruction,  // IF阶段读取的指令
    
    // ID阶段
    output [31:0] ID_PC,            // ID阶段的PC
    output [31:0] ID_instruction,  // ID阶段的指令
    output [5:0] ID_op,             // 操作码
    output [4:0] ID_rs,             // 源寄存器1
    output [4:0] ID_rt,             // 源寄存器2
    output [4:0] ID_rd,             // 目标寄存器
    
    // EX阶段
    output [31:0] EX_ALU_result,   // ALU运算结果
    
    // MEM阶段
    output [31:0] MEM_ALU_result,  // MEM阶段的ALU结果
    
    // WB阶段
    output [31:0] WB_WriteData,    // 写回数据
    output [4:0] WB_WriteReg,      // 写回寄存器地址
    output WB_RegWre               // 写回使能信号
);
```

### 2.2 时序要求

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 时钟频率 | 25 MHz | 周期40ns |
| 复位时间 | > 20ns | 低电平复位 |
| 建立时间 | 2ns | 数据在时钟边沿前稳定 |
| 保持时间 | 1ns | 数据在时钟边沿后保持 |

## 3. 系统层次结构

### 3.1 模块层次树

```
PipelineCPU (顶层)
│
├─ 取指阶段 (IF Stage)
│  ├─ PC (程序计数器)
│  ├─ InsMEM (指令存储器)
│  └─ IF_ID_Register (IF/ID流水线寄存器)
│
├─ 译码阶段 (ID Stage)
│  ├─ InstructionCut (指令分割器)
│  ├─ PipelineControlUnit (控制单元)
│  ├─ RegisterFile (寄存器堆)
│  ├─ SignZeroExtend (立即数扩展)
│  └─ ID_EX_Register (ID/EX流水线寄存器)
│
├─ 执行阶段 (EX Stage)
│  ├─ WriteRegSelector (写寄存器选择器)
│  ├─ ForwardingUnit (前推单元)
│  ├─ ALU (算术逻辑单元)
│  └─ EX_MEM_Register (EX/MEM流水线寄存器)
│
├─ 访存阶段 (MEM Stage)
│  ├─ DataMEM (数据存储器)
│  └─ MEM_WB_Register (MEM/WB流水线寄存器)
│
├─ 写回阶段 (WB Stage)
│  └─ (写回逻辑在寄存器堆中实现)
│
├─ 冒险处理
│  ├─ HazardDetectionUnit (冲突检测单元)
│  └─ ForwardingUnit (前推单元)
│
└─ 其他
   └─ pcAdd (PC计算单元)
```

## 4. 信号连接关系

### 4.1 主要信号总线

| 总线名称 | 位宽 | 方向 | 说明 |
|---------|------|------|------|
| PC总线 | 32 | IF→ID→EX→MEM→WB | 程序计数器在各阶段传递 |
| 指令总线 | 32 | IF→ID | 指令从存储器到译码 |
| 数据总线 | 32×2 | ID→EX | 两个寄存器读数据 |
| ALU结果总线 | 32 | EX→MEM→WB | ALU结果传递 |
| 存储器数据总线 | 32 | MEM→WB | 存储器读数据 |
| 写回总线 | 32 | WB→ID | 写回数据到寄存器堆 |
| 控制信号总线 | 多位 | ID→EX→MEM→WB | 控制信号传递 |

### 4.2 控制信号连接

```
┌─────────────────────────────────────────────────────┐
│                  控制信号流动                        │
└─────────────────────────────────────────────────────┘

PipelineControlUnit (ID阶段)
        │
        ├─ RegWre, RegDst, ALUSrcA, ALUSrcB, ALUOp
        │  mRD, mWR, DBDataSrc, WrRegDSrc, ExtSel
        │
        └─→ ID/EX寄存器 ─→ EX阶段使用部分信号
                 │
                 └─→ EX/MEM寄存器 ─→ MEM阶段使用部分信号
                          │
                          └─→ MEM/WB寄存器 ─→ WB阶段使用部分信号
```

### 4.3 冒险控制信号连接

```
┌─────────────────────────────────────────────────────┐
│               冒险检测与处理信号                     │
└─────────────────────────────────────────────────────┘

HazardDetectionUnit
        │
        ├─ PC_Write ──────→ PC模块
        ├─ IF_ID_Write ───→ IF/ID寄存器
        ├─ IF_Flush ──────→ IF/ID寄存器
        └─ ID_EX_Flush ───→ ID/EX寄存器

ForwardingUnit
        │
        ├─ ForwardA[1:0] ─→ ALU输入A选择
        └─ ForwardB[1:0] ─→ ALU输入B选择
```

## 5. 数据流动路径

### 5.1 正常指令执行流程

```
周期T: 指令I1   I2   I3   I4   I5
      ─────────────────────────────
阶段   IF   ID   EX  MEM   WB
      ─────────────────────────────
操作   取指→译码→执行→访存→写回

数据流:
I1: PC → InsMEM → IF/ID → RegFile → ID/EX → ALU → EX/MEM → DataMEM → MEM/WB → RegFile
```

### 5.2 数据前推路径

```
场景：指令I2需要I1的结果

正常情况（无前推）:
周期:  1    2    3    4    5    6
I1:   IF   ID   EX  MEM   WB
I2:        IF   ID   暂停  EX   MEM

使用前推:
周期:  1    2    3    4    5
I1:   IF   ID   EX  MEM   WB
I2:        IF   ID   EX   MEM
                    ↑
                    └─ 从EX/MEM前推数据

前推路径:
I1_result (EX/MEM) ─→ ForwardingUnit ─→ MUX ─→ ALU输入 (I2)
```

### 5.3 Load-Use冒险处理

```
场景：Load指令后立即使用

周期:  1    2    3    4    5    6
LW:   IF   ID   EX  MEM   WB
ADD:       IF   ID   气泡  EX   MEM
                ↑
                └─ 检测到冒险，插入气泡

处理流程:
1. HazardDetectionUnit检测到Load-Use冒险
2. 产生控制信号: PC_Write=0, IF_ID_Write=0, ID_EX_Flush=1
3. PC和IF/ID保持不变
4. ID/EX插入NOP（气泡）
5. 下一周期正常前推
```

## 6. 存储器系统

### 6.1 指令存储器（InsMEM）

```
┌────────────────────────────────┐
│        指令存储器(InsMEM)       │
├────────────────────────────────┤
│ 容量: 128字节                   │
│ 组织: 32位×32条指令             │
│ 访问: 只读                      │
│ 初始化: 从MIPS.txt加载          │
│ 地址: 字节寻址（0-127）         │
└────────────────────────────────┘

地址映射:
0x00 - 0x03: 指令0
0x04 - 0x07: 指令1
...
0x7C - 0x7F: 指令31
```

### 6.2 数据存储器（DataMEM）

```
┌────────────────────────────────┐
│        数据存储器(DataMEM)      │
├────────────────────────────────┤
│ 容量: 32字节                    │
│ 组织: 32位×8个字                │
│ 访问: 读写                      │
│ 地址: 字节寻址（0-31）          │
└────────────────────────────────┘

地址映射:
0x00 - 0x03: 数据字0
0x04 - 0x07: 数据字1
...
0x1C - 0x1F: 数据字7
```

### 6.3 寄存器堆（RegisterFile）

```
┌────────────────────────────────┐
│        寄存器堆(RegisterFile)   │
├────────────────────────────────┤
│ 数量: 32个寄存器                 │
│ 位宽: 32位                      │
│ 读端口: 2个（组合逻辑）          │
│ 写端口: 1个（时钟下降沿）        │
│ $0: 恒为0（硬件保证）            │
└────────────────────────────────┘

特殊寄存器:
$0  : 常量0
$31 : 返回地址（JAL使用）
```

## 7. 时钟域与复位

### 7.1 时钟分布

```
              CLK (全局时钟)
                   │
       ┌───────────┼───────────┐
       │           │           │
       ↓           ↓           ↓
      PC      流水线寄存器   寄存器堆
    (上升沿)    (上升沿)    (下降沿)
```

### 7.2 复位策略

```
RST (异步复位，低电平有效)
  │
  ├─→ PC = 0
  ├─→ IF/ID寄存器清零
  ├─→ ID/EX寄存器清零
  ├─→ EX/MEM寄存器清零
  └─→ MEM/WB寄存器清零

复位序列:
1. RST = 0 (至少20ns)
2. 所有流水线寄存器清零
3. PC初始化为0
4. RST = 1
5. 开始正常执行
```

## 8. 性能参数

### 8.1 流水线效率

| 参数 | 理想值 | 实际值 | 说明 |
|------|--------|--------|------|
| CPI | 1.0 | 1.2-1.5 | 周期每指令 |
| IPC | 1.0 | 0.67-0.83 | 指令每周期 |
| 流水线利用率 | 100% | 70-85% | 考虑暂停和清空 |
| 加速比 | 5× | 3-4× | 相对于多周期CPU |

### 8.2 冒险统计（典型程序）

| 冒险类型 | 发生频率 | 处理周期 | 性能损失 |
|---------|---------|---------|---------|
| Load-Use | 5-10% | 1周期暂停 | 5-10% |
| EX冒险 | 15-20% | 0周期（前推） | 0% |
| MEM冒险 | 10-15% | 0周期（前推） | 0% |
| 控制冒险 | 10-15% | 1-2周期 | 10-30% |

### 8.3 临界路径

```
最长路径（决定最高时钟频率）:

寄存器读取 → 前推MUX → ALU运算 → 结果MUX → 寄存器写入

估算延迟:
- 寄存器读取: 2ns
- 前推MUX: 1ns
- ALU运算: 8ns (加法器)
- 结果MUX: 1ns
- 寄存器建立时间: 2ns
- 时钟偏斜: 1ns

总计: ~15ns → 最高频率约66MHz
当前设计: 25MHz (40ns周期) → 有充足裕量
```

## 9. 设计约束

### 9.1 资源限制

| 资源 | 数量 | 说明 |
|------|------|------|
| 指令存储器 | 128字节 | 可存储32条指令 |
| 数据存储器 | 32字节 | 可存储8个32位数据 |
| 通用寄存器 | 32个 | $0-$31 |
| 流水线级数 | 5级 | IF-ID-EX-MEM-WB |

### 9.2 功能限制

- 不支持中断和异常处理
- 不支持虚拟内存
- 分支预测采用"总是不跳转"策略
- 不支持流水线深度动态调整
- 不支持乱序执行
