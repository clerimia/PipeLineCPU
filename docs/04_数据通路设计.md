# 数据通路设计

## 五级流水线数据通路概览

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        五级流水线CPU数据通路                                 │
└─────────────────────────────────────────────────────────────────────────────┘

   IF Stage         ID Stage         EX Stage        MEM Stage       WB Stage
  ┌────────┐      ┌────────┐      ┌────────┐      ┌────────┐      ┌────────┐
  │        │      │        │      │        │      │        │      │        │
  │  取指  │ ───> │  译码  │ ───> │  执行  │ ───> │  访存  │ ───> │  写回  │
  │        │      │        │      │        │      │        │      │        │
  └────────┘      └────────┘      └────────┘      └────────┘      └────────┘
      ↓               ↓               ↓               ↓               ↓
   IF/ID          ID/EX           EX/MEM          MEM/WB         寄存器堆
  流水线寄存器    流水线寄存器    流水线寄存器    流水线寄存器
```

---

## 1. IF阶段 - 取指令（Instruction Fetch）

### 数据通路图

```
              ┌──────────┐
     RST ─────┤          │
     CLK ─────┤    PC    │
  PC_Write ───┤          │
   PCWre ─────┤          ├─── curPC [31:0]
              └──────────┘
                    │
                    │ PC地址
                    ↓
              ┌──────────┐
              │          │
   curPC ─────┤  InsMEM  │
              │          ├─── instruction [31:0]
              │(MIPS.txt)│
              └──────────┘
                    │
                    │ 指令
                    ↓
              ┌──────────┐
     CLK ─────┤          │
     RST ─────┤  IF/ID   │
IF_ID_Write ──┤ Register │
 IF_Flush ────┤          ├─── IF_ID_instruction [31:0]
              └──────────┘         IF_ID_PC [31:0]
```

### 主要部件

1. **PC (程序计数器)**
   - 输入：nextPC, PCWre, PC_Write
   - 输出：curPC
   - 功能：保存当前指令地址

2. **InsMEM (指令存储器)**
   - 输入：curPC
   - 输出：instruction
   - 功能：根据地址读取指令

3. **IF/ID寄存器**
   - 输入：instruction, PC, IF_ID_Write, IF_Flush
   - 输出：IF_ID_instruction, IF_ID_PC
   - 功能：暂存IF阶段结果，传递给ID阶段

### 数据流动
```
PC → InsMEM → instruction → IF/ID → 下一阶段
```

## 2. ID阶段 - 指令译码（Instruction Decode）

### 数据通路图

```
                    IF/ID_instruction
                           │
                           ↓
                  ┌─────────────────┐
                  │ InstructionCut  │
                  │   (指令分割)     │
                  └─────────────────┘
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
     op[5:0]           rs[4:0]            rt[4:0]
        │              rt[4:0]            rd[4:0]
        │              sa[4:0]            immediate[15:0]
        │              addr[25:0]
        ↓
  ┌──────────┐           ↓                    ↓
  │          │      ┌──────────┐         ┌──────────┐
  │ Control  │      │          │         │  SignZero│
  │  Unit    │      │ Register │         │  Extend  │
  │          │      │   File   │         │          │
  └──────────┘      │          │         └──────────┘
        │           └──────────┘              │
        │                 │                   │
        │           ReadData1              extend
        │           ReadData2                 │
        │                 │                   │
        └─────────────────┼───────────────────┘
                          ↓
                    ┌──────────┐
             CLK ───┤          │
             RST ───┤  ID/EX   │─── 控制信号
      ID_EX_Flush ──┤ Register │─── ReadData1, ReadData2
                    │          │─── extend, rs, rt, rd, sa
                    └──────────┘
```

### 主要部件

1. **InstructionCut (指令分割)**
   - 输入：IF_ID_instruction
   - 输出：op, rs, rt, rd, sa, immediate, addr
   - 功能：提取指令各字段

2. **PipelineControlUnit (控制单元)**
   - 输入：op
   - 输出：RegWre, RegDst, ALUSrcA, ALUSrcB, ALUOp, mRD, mWR等
   - 功能：生成控制信号

3. **RegisterFile (寄存器堆)**
   - 输入：ReadReg1(rs), ReadReg2(rt), WriteReg, WriteData, RegWre
   - 输出：ReadData1, ReadData2
   - 功能：读取寄存器数据

4. **SignZeroExtend (立即数扩展)**
   - 输入：immediate, ExtSel
   - 输出：extend
   - 功能：扩展立即数到32位

5. **ID/EX寄存器**
   - 输入：控制信号、数据
   - 输出：ID_EX_*
   - 功能：传递到EX阶段

6. **PCSrc生成逻辑（关键修复）**
   - 输入：ID_op, ReadData1, ReadData2, EX_MEM_ALU_result, EX_MEM_WriteReg, EX_MEM_RegWre, addr
   - 输出：PCSrc[1:0]
   - 功能：在ID阶段判断分支/跳转条件，生成PC选择信号
   - **前推逻辑**：支持从MEM阶段前推数据到分支比较
     ```verilog
     // MEM阶段前推到ID阶段分支比较
     Branch_ReadData1 = (EX_MEM_RegWre && EX_MEM_WriteReg == ID_rs) ? 
                        EX_MEM_ALU_result : ReadData1;
     Branch_ReadData2 = (EX_MEM_RegWre && EX_MEM_WriteReg == ID_rt) ? 
                        EX_MEM_ALU_result : ReadData2;
     ```
   - 分支判断逻辑（使用前推后的数据）：
     - **BEQ**: 如果Branch_ReadData1 == Branch_ReadData2, 则PCSrc = 2'b01
     - **BNE**: 如果Branch_ReadData1 != Branch_ReadData2, 则PCSrc = 2'b01
     - **BLTZ**: 如果Branch_ReadData1[31] == 1, 则PCSrc = 2'b01
     - **J/JAL**: PCSrc = 2'b11
     - **JR**: PCSrc = 2'b10
     - **其他**: PCSrc = 2'b00 (PC+4)

7. **分支跳转清空逻辑**
   - 条件：is_branch_op && (PCSrc != 2'b00) && PC_Write
   - 效果：只有当分支**实际跳转**且**未暂停**时才清空IF阶段
   - 避免：暂停时错误地清空分支指令本身

### 数据流动
```
指令 → 分割 → 控制信号生成
           ↘ 寄存器读取 → ID/EX → 下一阶段
           ↘ 立即数扩展 ↗
```

## 3. EX阶段 - 执行（Execute）

### 数据通路图

```
                    ID/EX流水线寄存器输出
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
    RegDst[1:0]        ReadData1            ReadData2
    rt, rd             sa, extend           rs, rt
        │                   │                   │
        ↓                   ↓                   ↓
  ┌──────────┐        ┌─────────┐         ┌──────────┐
  │  Write   │        │         │         │          │
  │   Reg    │        │   MUX   │←────────┤Forwarding│
  │ Selector │        │ (前推)   │  ForwardA│   Unit   │
  └──────────┘        └─────────┘  ForwardB└──────────┘
        │                   │                   ↑
        │                   │                   │
    WriteReg               ↓                   EX_MEM_WriteReg
        │             ALU输入A/B                MEM_WB_WriteReg
        │                   │
        │                   ↓
        │              ┌─────────┐
        │              │   ALU   │
        │       ALUOp ─┤         │
        │       sa ────┤         │─── result [31:0]
        │    extend ───┤         │─── zero
        │              └─────────┘
        │                   │
        └───────────────────┼────────────────┐
                            │                │
                            ↓                │
                      ┌──────────┐           │
               CLK ───┤          │           │
               RST ───┤  EX/MEM  │───────────┘
                      │ Register │─── 控制信号
                      │          │─── ALU_result
                      └──────────┘─── ReadData2
                                      WriteReg, zero
```

### 主要部件

1. **WriteRegSelector (写寄存器选择)**
   - 输入：RegDst, rt, rd
   - 输出：WriteReg
   - 功能：选择目标寄存器

2. **ForwardingUnit (前推单元)**
   - 输入：ID_EX_rs, ID_EX_rt, EX_MEM_WriteReg, MEM_WB_WriteReg
   - 输出：ForwardA, ForwardB
   - 功能：检测数据冒险，生成前推控制

3. **ALU (算术逻辑单元)**
   - 输入：ReadData1, ReadData2, sa, extend, ForwardA, ForwardB, 前推数据
   - 输出：result, zero
   - 功能：执行运算，支持数据前推

4. **前推MUX**
   - 功能：根据ForwardA/B选择ALU输入
   - 数据源：寄存器堆、EX/MEM、MEM/WB

5. **EX/MEM寄存器**
   - 功能：传递到MEM阶段

### 前推数据路径

```
EX/MEM_ALU_result ─┐
                   ├─→ MUX (ForwardA/B) → ALU输入
MEM_WB_WriteData ──┘

优先级：EX/MEM > MEM/WB > 寄存器堆
```

### 数据流动
```
寄存器数据 → 前推MUX → ALU → result → EX/MEM → 下一阶段
前推数据 ──────↗
```

## 4. MEM阶段 - 访存（Memory Access）

### 数据通路图

```
                    EX/MEM流水线寄存器输出
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
    控制信号            ALU_result           ReadData2
    (mRD, mWR)              │              (SW数据)
        │                   │                   │
        │                   ↓                   ↓
        │              ┌──────────┐
        └─────────────→│          │
                       │ DataMEM  │
          ALU_result ──┤          │─── MemData [31:0]
          ReadData2 ───┤          │
                       │          │
                       └──────────┘
                            │
                            │
                            ↓
                      ┌──────────┐
               CLK ───┤          │
               RST ───┤  MEM/WB  │─── 控制信号
                      │ Register │─── MemData
                      │          │─── ALU_result
                      └──────────┘─── WriteReg
```

### 主要部件

1. **DataMEM (数据存储器)**
   - 输入：DAddr(ALU_result), DataIn(ReadData2), mRD, mWR
   - 输出：DataOut
   - 功能：读写数据

2. **MEM/WB寄存器**
   - 输入：MemData, ALU_result, WriteReg, 控制信号
   - 输出：MEM_WB_*
   - 功能：传递到WB阶段

### 数据流动

**Load指令**：
```
ALU_result (地址) → DataMEM → MemData → MEM/WB → WriteData
```

**Store指令**：
```
ReadData2 (数据) → DataMEM
ALU_result (地址) →    ↑
```

**其他指令**：
```
ALU_result → MEM/WB → WriteData
```

### 数据通路图

```
                    MEM/WB流水线寄存器输出
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
    DBDataSrc           MemData             ALU_result
        │                   │                   │
        │                   └───────┬───────────┘
        │                           │
        │                           ↓
        │                      ┌─────────┐
        └─────────────────────→│   MUX   │
                               │ (选择)   │

                                     │

                                     ↓
                              ┌──────────┐

                   WriteReg ──┤Register  │

                              │          │
```

### 主要部件

   - 输出：WriteData

2. **RegisterFile写端口**
   - 输入：WriteReg, WriteData, RegWre

**Load指令**：
```
MEM/WB_MemData → MUX → WriteData → RegisterFile
```

**其他指令**：
```
MEM/WB_ALU_result → MUX → WriteData → RegisterFile
```

## 6. 冒险处理数据通路

### 6.1 数据前推路径

```
                    前推数据流
                    
EX阶段需要的数据 ←─── MEM阶段产生的数据 (EX/MEM_ALU_result)
     │                      │
     │                      │ ForwardA/B = 10
     │                      │
     └────────────────────← WB阶段产生的数据 (MEM_WB_WriteData)
                            │
                            │ ForwardA/B = 01
                            
优先级：MEM > WB > 寄存器堆
```

### 6.2 流水线暂停控制

```
                Load-Use冒险检测
                        │
                        ↓
            ┌───────────────────────┐
            │ HazardDetectionUnit   │
            │                       │
  ID_rs ────┤  检测EX阶段Load指令   │─── PC_Write = 0
  ID_rt ────┤  与ID阶段源寄存器     │─── IF_ID_Write = 0
EX_WriteReg─┤  是否相同             │─── ID_EX_Flush = 1
  EX_mRD ───┤                       │
            └───────────────────────┘
                        │
                        ↓
                 插入气泡（NOP）
```

### 6.3 流水线清空控制

```
              控制冒险（跳转/分支）
                        │
                        ↓
            ┌───────────────────────┐
            │ HazardDetectionUnit   │
            │                       │
   ID_op ───┤  检测跳转指令：     ├─── IF_Flush = 1
            │    J, JAL, JR        │
            │                       │
            │  分支指令由          │
            │  PipelineCPU处理    │
            └───────────────────────┘
                        │
                        ↓
                清空IF/ID寄存器
```

**分支指令条件清空（关键修复）**：
``verilog
// 在PipelineCPU中
assign is_branch_op = (ID_op == 6'b110100) ||  // beq
                      (ID_op == 6'b110101) ||  // bne
                      (ID_op == 6'b110110);    // bltz
                      
assign branch_taken_flush = is_branch_op && 
                           (PCSrc != 2'b00) &&  // 实际跳转
                           PC_Write;            // 未暂停
                           
assign IF_Flush = IF_Flush_hazard | branch_taken_flush;
```

**为什么重要**：
- 避免分支暂停时错误清空分支指令本身
- 确保只在分支跳转时清空已取的下一条指令

### 6.4 PC计算源选择（关键修复）

**问题**：分支跳转后，IF被flush，IF_ID_PC变为0，导致PC计算错误

**解决方案**：
``verilog
// 动态选择PC源
assign pcAdd_curPC = (PCSrc == 2'b01) ? IF_ID_PC : IF_PC;

pcAdd pcAdd_inst(
  .curPC(pcAdd_curPC),  // 分支用IF_ID_PC，其他用IF_PC
  .PCSrc(PCSrc),
  .immediate(extend),
  .nextPC(nextPC)
);
```

**原理**：
- PCSrc=01（分支）：使用IF_ID_PC（分支指令的PC）
- PCSrc=00/10/11：使用IF_PC（当前IF阶段的PC）
- 避免使用被flush后的零值

## 7. 完整数据通路连接

### 7.1 主数据通路

```
PC → InsMEM → IF/ID → InstructionCut
                          ↓
                    RegisterFile → ID/EX → ALU → EX/MEM
                          ↑                          ↓
                          │                     DataMEM → MEM/WB
                          │                                  ↓
                          └──────────────────────────────────────┘
                                  (写回路径)
```

### 7.2 控制信号通路

```
InstructionCut(op) → PipelineControlUnit
                             ↓
                        ID/EX → EX/MEM → MEM/WB
                        (控制信号随流水线传递)
```

### 7.3 冒险检测通路

```
ID阶段(rs,rt,op) ┌
EX阶段(WriteReg) ├→ HazardDetectionUnit → PC_Write
                 │                      → IF_ID_Write
                 │                      → IF_Flush
                 └──────────────────────→ → ID_EX_Flush
```

### 7.4 前推通路

```
ID/EX(rs,rt) ────┌
EX/MEM(WriteReg) ├→ ForwardingUnit → ForwardA/B
MEM/WB(WriteReg) ┘                         ↓
                                          ALU
EX/MEM_ALU_result ─────────────────────────→  ↑
MEM_WB_WriteData ──────────────────────────→  ↑
                    (前推数据)

分支前推通路 (关键添加)：
EX_MEM_ALU_result ─────────────────────────→ Branch_ReadData1/2
                                           (ID阶段分支比较)
```

## 8. 数据通路时序

### 时钟周期内的操作

```
时钟周期 T:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  IF(T)  │  ID(T-1)  │  EX(T-2)  │  MEM(T-3)  │  WB(T-4)   │
│         │           │           │             │            │
│  取指   │   译码    │   执行    │    访存     │   写回     │
│         │           │           │             │            │
└─────────────────────────────────────────────────────────────┘
         ↑           ↑           ↑             ↑            ↑
      时钟上升沿  (流水线寄存器更新)
```

### 数据传递时序

```
周期1: 指令1进入IF
周期2: 指令1进入ID, 指令2进入IF
周期3: 指令1进入EX, 指令2进入ID, 指令3进入IF
周期4: 指令1进入MEM, 指令2进入EX, 指令3进入ID, 指令4进入IF
周期5: 指令1进入WB, 指令2进入MEM, 指令3进入EX, 指令4进入ID, 指令5进入IF
```

### 冒险处理时序

**正常情况（无冒险）**：
```
周期:  1    2    3    4    5
指令1: IF   ID   EX   MEM  WB
指令2:      IF   ID   EX   MEM
指令3:           IF   ID   EX
```

**Load-Use冒险（插入气泡）**：
```
周期:  1    2    3    4    5    6
指令1: IF   ID   EX   MEM  WB
指令2:      IF   ID   暂停  EX   MEM  (Load)
指令3:           IF   气泡  ID   EX   (Use)
```

**控制冒险（清空流水线）**：
```
周期:  1    2    3    4    5
指令1: IF   ID   EX   MEM  WB   (分支)
指令2:      IF   清空              (被清空)
指令3:           IF   ID   EX      (分支目标)
```
