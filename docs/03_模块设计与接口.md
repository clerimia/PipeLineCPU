# 模块设计与接口描述

## 模块层次结构

```
PipelineCPU (顶层模块)
├── PC (程序计数器)
├── InsMEM (指令存储器)
├── IF_ID_Register (IF/ID流水线寄存器)
├── InstructionCut (指令分割器)
├── PipelineControlUnit (流水线控制单元)
├── RegisterFile (寄存器堆)
├── SignZeroExtend (立即数扩展器)
├── ID_EX_Register (ID/EX流水线寄存器)
├── WriteRegSelector (写寄存器选择器)
├── ForwardingUnit (前推单元)
├── ALU (算术逻辑单元)
├── EX_MEM_Register (EX/MEM流水线寄存器)
├── DataMEM (数据存储器)
├── MEM_WB_Register (MEM/WB流水线寄存器)
├── HazardDetectionUnit (冲突检测单元)
└── pcAdd (PC计算单元)
```

---

## 1. 顶层模块 - PipelineCPU

### 功能描述
五级流水线CPU的顶层模块，连接所有子模块，实现完整的MIPS流水线架构。

### 接口定义

```verilog
module PipelineCPU(
    // 输入
    input CLK,                  // 时钟信号
    input RST,                  // 复位信号（低电平有效）
    
    // 调试输出
    output [31:0] curPC,        // 当前PC值
    output [31:0] IF_PC,        // IF阶段PC
    output [31:0] IF_instruction,  // IF阶段指令
    output [31:0] ID_PC,        // ID阶段PC
    output [31:0] ID_instruction,  // ID阶段指令
    output [5:0] ID_op,         // ID阶段操作码
    output [4:0] ID_rs,         // ID阶段rs
    output [4:0] ID_rt,         // ID阶段rt
    output [4:0] ID_rd,         // ID阶段rd
    output [31:0] EX_ALU_result,   // EX阶段ALU结果
    output [31:0] MEM_ALU_result,  // MEM阶段ALU结果
    output [31:0] WB_WriteData,    // WB阶段写回数据
    output [4:0] WB_WriteReg,      // WB阶段写回寄存器
    output WB_RegWre               // WB阶段写使能
);
```

### 参数说明
无参数，所有位宽固定

### 功能说明
- 组织五级流水线的数据通路
- 连接冲突检测和前推单元
- 提供调试观察接口

## 2. IF阶段模块

### 2.1 PC (程序计数器)

```verilog
module PC(
    input CLK,                  // 时钟信号
    input RST,                  // 复位信号
    input PCWre,                // PC写使能（指令级）
    input PC_Write,             // PC写使能（流水线控制）
    input [31:0] nextPC,        // 下一条指令地址
    output reg [31:0] curPC     // 当前指令地址
);
```

**功能**：保存当前指令地址，支持流水线暂停控制

**关键逻辑**：
- PC更新条件：`PCWre && PC_Write`
- 复位时：`curPC = 0`
- HALT指令：`PCWre = 0`
- 流水线暂停：`PC_Write = 0`

---

### 2.2 InsMEM (指令存储器)

```verilog
module InsMEM(
    input [31:0] IAddr,         // 指令地址
    input InsMemRW,             // 读写控制（1=读，0=写）
    output reg [31:0] IDataOut  // 指令数据输出
);
```

**功能**：存储程序指令，支持从文件加载

**存储结构**：
- 容量：128字节（32条指令）
- 组织：按字节存储，大端模式
- 初始化：从MIPS.txt文件读取

---

### 2.3 IF_ID_Register (IF/ID流水线寄存器)

```verilog
module IF_ID_Register(
    input CLK,
    input RST,
    input IF_ID_Write,          // 写使能（暂停控制）
    input IF_Flush,             // 清空信号
    input [31:0] PC_in,
    input [31:0] instruction_in,
    output reg [31:0] PC_out,
    output reg [31:0] instruction_out
);
```

**功能**：IF和ID阶段之间的流水线寄存器

**控制逻辑**：
- `IF_Flush=1`：插入NOP（气泡）
- `IF_ID_Write=0`：保持当前值（暂停）
- 其他情况：正常传递

## 3. ID阶段模块

### 3.1 InstructionCut (指令分割器)

```verilog
module InstructionCut(
    input [31:0] instruction,   // 32位指令
    output reg [5:0] op,        // 操作码
    output reg [4:0] rs,        // 源寄存器1
    output reg [4:0] rt,        // 源寄存器2
    output reg [4:0] rd,        // 目标寄存器
    output reg [4:0] sa,        // 移位量
    output reg [15:0] immediate,// 立即数
    output reg [25:0] addr      // 跳转地址
);
```

**功能**：将32位指令分解为各个字段

**字段提取**：
- op = instruction[31:26]
- rs = instruction[25:21]
- rt = instruction[20:16]
- rd = instruction[15:11]
- sa = instruction[10:6]
- immediate = instruction[15:0]
- addr = instruction[25:0]

---

### 3.2 PipelineControlUnit (流水线控制单元)

```verilog
module PipelineControlUnit(
    input [5:0] op,             // 操作码
    
    // 控制信号输出
    output reg RegWre,          // 寄存器写使能
    output reg [1:0] RegDst,    // 写寄存器选择
    output reg ALUSrcA,         // ALU输入A选择
    output reg ALUSrcB,         // ALU输入B选择
    output reg [2:0] ALUOp,     // ALU操作
    output reg mRD,             // 存储器读
    output reg mWR,             // 存储器写
    output reg DBDataSrc,       // 写回数据源
    output reg WrRegDSrc,       // 写寄存器数据源
    output reg ExtSel           // 立即数扩展方式
);
```

**功能**：根据操作码生成控制信号（组合逻辑，无状态机）

**特点**：
- 纯组合逻辑
- 每个指令一个case分支
- 控制信号在ID阶段生成，随流水线传递

---

### 3.3 RegisterFile (寄存器堆)

```verilog
module RegisterFile(
    input CLK,
    input [4:0] ReadReg1,       // 读端口1地址
    input [4:0] ReadReg2,       // 读端口2地址
    input [4:0] WriteReg,       // 写端口地址
    input [31:0] WriteData,     // 写数据
    input RegWre,               // 写使能
    output reg [31:0] ReadData1,// 读端口1数据
    output reg [31:0] ReadData2 // 读端口2数据
);
```

**功能**：32个32位通用寄存器，支持同时2读1写

**特性**：
- $0恒为0（硬件保证）
- 内部前推：同周期写后读直接前推
- 写操作在时钟下降沿
- 读操作为组合逻辑

---

### 3.4 SignZeroExtend (立即数扩展器)

```verilog
module SignZeroExtend(
    input wire [15:0] immediate,    // 16位立即数
    input ExtSel,                   // 扩展方式选择
    output [31:0] extendImmediate   // 32位扩展结果
);
```

**功能**：将16位立即数扩展为32位

**扩展方式**：
- ExtSel=0：零扩展（高位补0）
- ExtSel=1：符号扩展（高位补符号位）

---

### 3.5 ID_EX_Register (ID/EX流水线寄存器)

```verilog
module ID_EX_Register(
    input CLK,
    input RST,
    input ID_EX_Flush,          // 清空信号
    
    // 控制信号输入/输出（9个）
    input RegWre_in,
    input [1:0] RegDst_in,
    input ALUSrcA_in,
    input ALUSrcB_in,
    input [2:0] ALUOp_in,
    input mRD_in,
    input mWR_in,
    input DBDataSrc_in,
    input WrRegDSrc_in,
    output reg RegWre_out,
    // ... 其他控制信号
    
    // 数据输入/输出
    input [31:0] PC_in,
    input [31:0] ReadData1_in,
    input [31:0] ReadData2_in,
    input [31:0] extend_in,
    input [4:0] rs_in,
    input [4:0] rt_in,
    input [4:0] rd_in,
    input [4:0] sa_in,
    output reg [31:0] PC_out,
    // ... 其他数据输出
);
```

**功能**：ID和EX阶段之间的流水线寄存器

**传递内容**：
- 9个控制信号
- PC值、两个寄存器数据、扩展立即数
- rs、rt、rd、sa字段

## 4. EX阶段模块

### 4.1 WriteRegSelector (写寄存器选择器)

```verilog
module WriteRegSelector(
    input [1:0] RegDst,         // 选择信号
    input [4:0] rt,
    input [4:0] rd,
    output reg [4:0] WriteReg   // 目标寄存器
);
```

**功能**：根据RegDst选择写回的寄存器地址

**选择逻辑**：
- RegDst=00：WriteReg = 31 (JAL)
- RegDst=01：WriteReg = rt (I型)
- RegDst=10：WriteReg = rd (R型)

---

### 4.2 ForwardingUnit (前推单元)

```verilog
module ForwardingUnit(
    // EX阶段源寄存器
    input [4:0] ID_EX_rs,
    input [4:0] ID_EX_rt,
    
    // MEM阶段写回信息
    input [4:0] EX_MEM_WriteReg,
    input EX_MEM_RegWre,
    
    // WB阶段写回信息
    input [4:0] MEM_WB_WriteReg,
    input MEM_WB_RegWre,
    
    // 前推控制输出
    output reg [1:0] ForwardA,  // ALU输入A前推
    output reg [1:0] ForwardB   // ALU输入B前推
);
```

**功能**：检测数据冒险，生成前推控制信号

**前推优先级**：
1. EX冒险（MEM→EX）优先级最高
2. MEM冒险（WB→EX）优先级次之

---

### 4.3 ALU (算术逻辑单元)

```verilog
module ALU(
    input ALUSrcA,
    input ALUSrcB,
    input [31:0] ReadData1,
    input [31:0] ReadData2,
    input [4:0] sa,
    input [31:0] extend,
    input [2:0] ALUOp,
    
    // 前推输入
    input [1:0] ForwardA,
    input [1:0] ForwardB,
    input [31:0] MEM_ForwardData,
    input [31:0] WB_ForwardData,
    
    output reg zero,
    output reg [31:0] result
);
```

**功能**：执行算术和逻辑运算，支持数据前推

**运算类型**：
- 加减法（ADD, SUB, ADDI）
- 逻辑运算（OR, AND, XOR, ORI）
- 移位（SLL）
- 比较（SLT, SLTU, SLTIU）

**前推逻辑**：
- 根据ForwardA/B选择ALU输入数据源
- 优先使用前推数据，否则使用寄存器数据

---

## 6. 冒险处理模块

### 6.1 HazardDetectionUnit (冲突检测单元)

```verilog
module HazardDetectionUnit(
    // ID阶段信息
    input [4:0] ID_rs,
    input [4:0] ID_rt,
    input [5:0] ID_op,
    
    // EX阶段信息
    input [4:0] EX_rt,
    input [4:0] EX_WriteReg,
    input EX_mRD,
    input EX_RegWre,
    
    // MEM阶段信息
    input [5:0] MEM_op,
    input MEM_zero,
    
    // 控制信号输出
    output reg PC_Write,        // PC写使能
    output reg IF_ID_Write,     // IF/ID写使能
    output reg IF_Flush,        // IF清空
    output reg ID_EX_Flush      // ID/EX清空
);
```

**功能**：检测流水线冒险，生成暂停和清空信号

**检测类型**：
1. Load-Use冒险 → 暂停流水线
2. 控制冒险（跳转、分支）→ 清空流水线
3. HALT指令 → 停止流水线

## 7. 其他模块

### 7.1 pcAdd (PC计算单元)

```verilog
module pcAdd(
    input RST,
    input [1:0] PCSrc,          // PC源选择
    input [31:0] immediate,     // 分支偏移
    input [25:0] addr,          // 跳转地址
    input [31:0] curPC,         // 当前PC
    input [31:0] rs,            // 寄存器值（JR）
    output reg [31:0] nextPC    // 下一PC
);
```

**功能**：计算下一条指令地址

**计算方式**：
- PCSrc=00：nextPC = PC + 4
- PCSrc=01：nextPC = PC + 4 + immediate*4
- PCSrc=10：nextPC = rs
- PCSrc=11：nextPC = {PC[31:28], addr, 2'b00}

## 模块间连接关系

### 数据流动
```
InsMEM → IF/ID → InstructionCut
                      ↓
              RegisterFile → ID/EX → ALU → EX/MEM
                                              ↓
                                         DataMEM → MEM/WB → RegisterFile
```

### 控制流动
```
PipelineControlUnit → ID/EX → EX/MEM → MEM/WB

HazardDetectionUnit → PC, IF/ID, ID/EX (暂停/清空)

ForwardingUnit → ALU (前推选择)
```

### 反馈路径
```
MEM/WB → RegisterFile (写回)
MEM/WB → ForwardingUnit (前推检测)
EX/MEM → ForwardingUnit (前推检测)
EX/MEM → ALU (前推数据)
MEM/WB → ALU (前推数据)
```
