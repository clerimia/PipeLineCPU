## 📈 设计要点总结

### 架构特点
1. **五级经典流水线**: IF-ID-EX-MEM-WB
2. **数据前推**: 支持EX和MEM冒险的前推
3. **流水线暂停**: Load-Use冒险时插入气泡
4. **流水线清空**: 控制冒险时清空无效指令

### 性能指标
- **理想CPI**: 1.0
- **实际CPI**: 1.2-1.5
- **时钟频率**: 25MHz
- **加速比**: 3-4×（相对多周期CPU）

### 实现亮点
1. **完整的冒险处理机制**
2. **高效的数据前推路径**
3. **灵活的流水线控制**
4. **清晰的模块化设计**
