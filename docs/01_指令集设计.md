# 指令集设计

## 支持的MIPS指令 大端序

### 1. R型指令（寄存器型指令）

| 指令 | 操作码 | 功能 | 格式 | 说明 |
|------|--------|------|------|------|
| ADD | 000000 | 加法 | add $rd, $rs, $rt | rd = rs + rt |
| SUB | 000001 | 减法 | sub $rd, $rs, $rt | rd = rs - rt |
| OR | 010000 | 或运算 | or $rd, $rs, $rt | rd = rs \| rt |
| AND | 010001 | 与运算 | and $rd, $rs, $rt | rd = rs & rt |
| SLL | 011000 | 逻辑左移 | sll $rd, $rt, sa | rd = rt << sa |
| SLT | 100110 | 小于则置位（有符号） | slt $rd, $rs, $rt | rd = (rs < rt) ? 1 : 0 |

**指令格式：**
```
|   op   |   rs   |   rt   |   rd   |   sa   | funct |
| 31-26  | 25-21  | 20-16  | 15-11  | 10-6   |  5-0  |
```

---

### 2. I型指令（立即数型指令）

| 指令 | 操作码 | 功能 | 格式 | 说明 |
|------|--------|------|------|------|
| ADDI | 000010 | 立即数加法 | addi $rt, $rs, imm | rt = rs + SignExt(imm) |
| ORI | 010010 | 立即数或运算 | ori $rt, $rs, imm | rt = rs \| ZeroExt(imm) |
| SLTIU | 100111 | 立即数无符号小于置位 | sltiu $rt, $rs, imm | rt = (rs < ZeroExt(imm)) ? 1 : 0 |
| LW | 110001 | 加载字 | lw $rt, offset($rs) | rt = MEM[rs + SignExt(offset)] |
| SW | 110000 | 存储字 | sw $rt, offset($rs) | MEM[rs + SignExt(offset)] = rt |
| BEQ | 110100 | 相等则分支 | beq $rs, $rt, offset | if(rs == rt) PC = PC + 4 + offset*4 |
| BNE | 110101 | 不等则分支 | bne $rs, $rt, offset | if(rs != rt) PC = PC + 4 + offset*4 |
| BLTZ | 110110 | 小于零则分支 | bltz $rs, offset | if(rs < 0) PC = PC + 4 + offset*4 |

**指令格式：**
```
|   op   |   rs   |   rt   |      immediate      |
| 31-26  | 25-21  | 20-16  |       15-0          |
```

---

### 3. J型指令（跳转型指令）

| 指令 | 操作码 | 功能 | 格式 | 说明 |
|------|--------|------|------|------|
| J | 111000 | 无条件跳转 | j target | PC = {PC[31:28], target, 2'b00} |
| JAL | 111010 | 跳转并链接 | jal target | $31 = PC + 4; PC = {PC[31:28], target, 2'b00} |
| JR | 111001 | 寄存器跳转 | jr $rs | PC = rs |

**指令格式：**
```
|   op   |           address (target)           |
| 31-26  |                25-0                   |
```

---

### 4. 特殊指令

| 指令 | 操作码 | 功能 | 格式 | 说明 |
|------|--------|------|------|------|
| HALT | 111111 | 停机 | halt | 停止CPU运行 |

## ALU操作码

| ALUOp[2:0] | 操作 | 说明 |
|------------|------|------|
| 000 | ADD | 加法：result = A + B |
| 001 | SUB | 减法：result = A - B |
| 010 | SLTU | 无符号小于：result = (A < B) ? 1 : 0 |
| 011 | SLT | 有符号小于：result = (A < B) ? 1 : 0 |
| 100 | SLL | 逻辑左移：result = B << A |
| 101 | OR | 或运算：result = A \| B |
| 110 | AND | 与运算：result = A & B |
| 111 | XOR | 异或运算：result = A ^ B |

---

## 寄存器约定

| 寄存器 | 编号 | 用途 |
|--------|------|------|
| $0 | 0 | 恒为0（硬件保证） |
| $1-$31 | 1-31 | 通用寄存器 |
| $31 | 31 | 返回地址寄存器（JAL使用） |

---

## 立即数扩展

| 指令 | 扩展方式 | 说明 |
|------|----------|------|
| ADDI, LW, SW, BEQ, BNE, BLTZ | 符号扩展 | imm[15] → imm[31:16] |
| ORI, SLTIU | 零扩展 | 0 → imm[31:16] |

---

## 指令示例

### 算术运算
```assembly
addi $1, $0, 10      # $1 = 0 + 10 = 10
addi $2, $0, 20      # $2 = 0 + 20 = 20
add  $3, $1, $2      # $3 = $1 + $2 = 30
sub  $4, $2, $1      # $4 = $2 - $1 = 10
```

### 逻辑运算
```assembly
ori  $5, $0, 0xFF    # $5 = 0 | 0xFF = 0xFF
and  $6, $5, $3      # $6 = $5 & $3
or   $7, $5, $3      # $7 = $5 | $3
sll  $8, $1, 2       # $8 = $1 << 2 = 40
```

### 访存操作
```assembly
sw   $3, 0($0)       # MEM[0] = $3
lw   $9, 0($0)       # $9 = MEM[0]
```

### 分支跳转
```assembly
beq  $1, $2, label   # if($1 == $2) goto label
bne  $1, $2, label   # if($1 != $2) goto label
bltz $4, label       # if($4 < 0) goto label
j    target          # goto target
jal  function        # call function
jr   $31             # return
```
